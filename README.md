# Health Dashboard

A modern health dashboard web application that simulates wearable device data sync and displays health metrics with interactive graphs. Built for the CodeCircuit Hackathon.

## Features

- Real-time health metrics display (steps, heart rate, calories, sleep, active time)
- Interactive line charts with tooltips and overlays
- Simulated wearable device sync functionality
- Responsive design for all screen sizes
- Modern Material-UI components
- TypeScript for type safety

## Tech Stack

- React 18
- TypeScript
- Material-UI
- Chart.js
- Vite

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Project Structure

```
src/
  ├── components/     # React components
  ├── data/          # Mock data and types
  ├── types/         # TypeScript type definitions
  ├── utils/         # Utility functions
  └── assets/        # Static assets
```

## Development

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
